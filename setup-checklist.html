Class 4: Ears and a Voice

Private setup before the hour. Progress is saved in this browser only.

Step 1 of 12
This prepares your system; it does not build the talking bot. The bot is built in class from P1, P2 and P3. Never paste your bot token, OpenRouter key or chat ID into community chat.

1. Check your computer

Start Docker Desktop. Your Class 3 stack must exist at ~/brain and answer questions from the dashboard's Ask tab.

Windows

Open PowerShell and confirm WSL is installed:

wsl -l -v
Windows rule for every step below: your stack lives inside WSL, so open the WSL (Ubuntu/Debian) terminal and use the Mac/Linux/WSL commands. The PowerShell variants are only for people whose stack runs natively on Windows.

2. Fastest path: let Claude Code do steps 3 to 9 with you

This is the same installer the front door publishes. Run it in a folder you do not mind it writing to. It stops before building the bot, on purpose.

Windows PowerShell (native stack only)

Prefer to do it by hand, or want to check what it did? Every command it runs is below. Either way, tick this and continue.

5. Verify the checksum

Print the published hash and your file's hash, then compare them yourself:

Mac / Linux / WSL

grep PRECLASS SHA256SUMS
sha256sum class-04-voice-PRECLASS.zip
# Mac without sha256sum:
shasum -a 256 class-04-voice-PRECLASS.zip

Windows PowerShell

Select-String PRECLASS SHA256SUMS
(Get-FileHash class-04-voice-PRECLASS.zip -Algorithm SHA256).Hash.ToLower()
No match? Stop, delete the zip, download again. Do not unzip it.

6. Unzip into its own folder

The zip unpacks flat, so give it a destination or it scatters files across your workspace.

Mac / Linux / WSL

unzip -o class-04-voice-PRECLASS.zip -d class-04-voice-pack

Windows PowerShell

Expand-Archive -Path class-04-voice-PRECLASS.zip -DestinationPath class-04-voice-pack -Force

Read MISSING-FILES.md, README.md, CLAIMS-AUDIT.md, PREWORK.md and VERIFY.md. The included workflow/09-voice-ask.UNVERIFIED.json is study material: leave it inactive.

7. Prove Class 3 is healthy

Start the stack, then ask it one question it can answer and one it cannot:

cd ~/brain && docker compose up -d
until curl -fsS http://localhost:5678/healthz; do sleep 5; done
docker compose ps
curl -s -X POST http://localhost:5678/webhook/ask -H 'Content-Type: application/json' -d '{"question":"How much is the security deposit on the warehouse?"}'
curl -s -X POST http://localhost:5678/webhook/ask -H 'Content-Type: application/json' -d '{"question":"What is my employee health plan copay?"}'

n8n takes 25 to 90 seconds from cold; the loop waits for it. If Docker says permission denied, prefix the docker commands with sudo. There is no brain-up.sh in a student stack: that file is an instructor helper.

The first must cite a source. The second must return answered: false with no sources. Then run the pack's checker from anywhere:

bash ~/class-04/class-04-voice-pack/verify.sh

Right now Parts 1, 2, 3 and 5 must pass (stack, Class 3 answer and refusal, ffmpeg with libopus, both models). Parts 4 and 6 will fail until step 11. That is expected at this stage.

If Class 3 invents an out-of-scope answer, stop. Class 4 would speak the same wrong answer out loud.

8. Create a separate Telegram bot

In Telegram open @BotFather (blue check), press Start, then send these one at a time:

/newbot
My Brain
yourname_brain_bot

The second line is the display name, the third the username: it must be unique and end in bot. Copy the token into a password manager only. Do not reuse Content Mate's bot: one bot can have only one webhook. Optional hardening: /setjoingroups then Disable, /setprivacy then Enable.

The token is a password: never post it, screenshot it, or type it into a workflow node.

9. Start it, then get your chat ID

On the phone you will use in class, open your bot, press Start and send it hello. Then, in a private browser tab, open this with your token filled in:

https://api.telegram.org/bot<MY_TOKEN>/getUpdates

Find "chat":{"id":123456789 and write the number down privately. Do this now: once a webhook is active, getUpdates correctly returns 409 and this page stops working.

10. Get a public HTTPS URL for n8n

Telegram cannot call localhost. It needs a public HTTPS address that reaches your n8n on port 5678. If you already run n8n behind a domain and reverse proxy, use that URL and skip to step 11. Otherwise use a free Cloudflare quick tunnel: no account, no card.

Install cloudflared once

Windows PowerShell:
winget install --id Cloudflare.cloudflared --exact

Mac:
brew install cloudflared

Linux / WSL (Debian or Ubuntu):
curl -fL -o cloudflared.deb https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-linux-amd64.deb && sudo dpkg -i cloudflared.deb

Open the tunnel in its own terminal and leave it running

cloudflared tunnel --url http://localhost:5678

After a few seconds it prints a line like https://random-words.trycloudflare.com. That is your public URL. Check it from any browser: https://random-words.trycloudflare.com/healthz must show {"status":"ok"}.

The quick-tunnel URL changes every time you restart cloudflared. Keep that terminal open through the class. If it restarts, rerun step 11 with the new URL and re-activate the workflow in n8n.
Windows with Docker Desktop: the tunnel can run in PowerShell or inside WSL; both reach localhost:5678.

11. Private setup, then the n8n credential

In a terminal that is not being shared or recorded. The script asks for the public URL, the token and your chat ID with typing hidden, writes a mode-600 private file in the stack, adds a Compose override and recreates n8n. A normal restart is not enough.

bash ~/class-04/class-04-voice-pack/setup-telegram-private.sh --stack ~/brain
bash ~/class-04/class-04-voice-pack/setup-telegram-private.sh --stack ~/brain --status

Status must show the token and owner ID set (character counts only) and the public URL set. Now put the token into n8n as a credential:

  1. Open http://localhost:5678, Create Workflow, name it 09 - Voice ask.
  2. Add a Telegram Trigger, Trigger On: Message.
  3. Credential: Create New, name it exactly Brain Bot (Telegram).
  4. Copy the token to the clipboard without showing it, paste into the masked Access Token field, Save, wait for the green "Connection tested successfully", then clear the clipboard:
bash ~/class-04/class-04-voice-pack/setup-telegram-private.sh --stack ~/brain --copy-token
bash ~/class-04/class-04-voice-pack/setup-telegram-private.sh --stack ~/brain --clear-clipboard

Save the workflow and leave it Inactive. Never click the eye/reveal icon. Finally run the checker again; every part must pass now:

bash ~/class-04/class-04-voice-pack/verify.sh

12. Ready for class

You have a checked pack, a healthy Class 3, audio support, a separate Telegram bot, your chat ID, a public HTTPS URL, private setup and a tested credential. You do not have a talking bot yet, and that is correct. In class: P1 voice to text; P2 grounded answer; P3 spoken reply.

If a token ever shows on screen or in a chat: BotFather /revoke, rerun step 11, replace the n8n credential. Post the exact error text to the community, never the token.
