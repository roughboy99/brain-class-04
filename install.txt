## Step 9 - Private Telegram setup and public HTTPS

Telegram Trigger needs a public HTTPS URL that reaches this n8n instance. Localhost is
not reachable by Telegram. Ask me to keep the slide deck on the shared screen and run,
in an unshared terminal:

  bash setup-telegram-private.sh --stack ~/brain

The script reads the URL, token and owner ID with echo disabled, writes an ignored
mode-600 private file, adds a Compose override, and recreates n8n. This is required
because Class 2's Compose service does not inject arbitrary .env keys and a plain
`docker compose restart` does not apply changed Compose configuration.

Verify only with:

  bash setup-telegram-private.sh --stack ~/brain --status

Never ask me to print either value. Paste the token from the clipboard into the n8n
credential and clear it with `--clear-clipboard`.
